# Getting help with DiceBear

Thanks for using DiceBear.

## Documentation and playground

- [dicebear.com](https://www.dicebear.com): full docs, guides, and the
  style gallery
- [Playground](https://www.dicebear.com/playground): try every style
  and option in the browser before integrating
- [editor.dicebear.com](https://editor.dicebear.com): the standalone
  editor for generating and exporting avatars

## Reporting a bug or requesting a feature

File an issue in the repo that matches the problem:

- Rendering bugs, core API, CLI, language ports (PHP, Python, Rust, Go,
  Dart), docs site, editor →
  [`dicebear/dicebear`](https://github.com/dicebear/dicebear/issues)
- Avatar style art or definition fixes →
  [`dicebear/styles`](https://github.com/dicebear/styles/issues)
- JSON Schema for definitions or options →
  [`dicebear/schema`](https://github.com/dicebear/schema/issues)
- Self-hosted HTTP API →
  [`dicebear/api`](https://github.com/dicebear/api/issues)
- The Figma exporter plugin →
  [`dicebear/exporter-plugin-for-figma`](https://github.com/dicebear/exporter-plugin-for-figma/issues)

If you are not sure which repo applies, file the issue in
[`dicebear/dicebear`](https://github.com/dicebear/dicebear/issues) and we
will move it.

## Security

Do not file public issues for security vulnerabilities. See the
[DiceBear security policy](./SECURITY.md) and email
<contact@dicebear.com> instead.

## Questions and discussions

For usage questions, integration help, or general discussion, open a
[GitHub Discussion](https://github.com/dicebear/dicebear/discussions) in
the main repo.

## Commercial use

DiceBear itself is MIT-licensed. Avatar style artwork may carry separate
licenses; check the `LICENSE.md` in
[`dicebear/styles`](https://github.com/dicebear/styles) or the
metadata on the individual style before using it commercially.
